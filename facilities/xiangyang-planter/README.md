# 向陽路東側花圃與球場邊牆

向陽路（218881795）東側，球場長條建築（444902480）與網球場前方，里程 135.5～193.5m。

使用者 2026-11-18 現場說明（取代同日稍早的「路緣擋土牆＋欄杆」版本）：
- 向陽路路邊**沒有欄杆**。
- 路邊是一條與路面平行的花圃，裡面只有草、沒有花。
- 花圃碰到球場時直接做一面牆；牆上超過路面的部分做鐵網欄杆。

模型做法：
- `layout.js`：路線、側邊（-1 為東側）、里程範圍、路緣／草面高度、牆厚、鐵網高度（3m，與網球場圍網一致）等。範圍與尺寸為模型選值。
- `surface.js`：純幾何。沿路緣每 0.5m 往外找到球場或建築邊界，退 0.25m 當牆的位置（找不到的里程以前後內插並平滑），花圃寬約 3.2～4.0m。`heightAt` 給路緣與草面的行走高度，`blocked` 讓鐵網擋住行人，`footprints` 讓 index.html 從路緣到牆外裁掉原地形。
- `renderer.js`：路緣、草面、混凝土牆（球場側從球場地面高度起）、牆外到球場邊的平地，以及牆頂上的鐵網（柱、上中下橫桿、菱形網線）。

不改道路、路寬、坡度、建築、球場資料或地形高度場；只在花圃與牆的範圍內裁掉原地形顯示。
