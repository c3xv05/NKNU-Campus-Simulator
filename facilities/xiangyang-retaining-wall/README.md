# 向陽路擋土牆與欄杆

向陽路（218881795）在球場長條建築（444902480）與網球場一側，路面比建築地基高約 5.6m，路邊到建築只有約 3.5m。原本路緣外有 0.4～1.75m 的垂直斷崖，再接陡坡。

使用者 2026-11-18 決定：路緣改做擋土牆加欄杆，牆下土坡照原樣。

- `layout.js`：路線、側邊（-1 為建築／網球場側）、起訖里程 135.5～193.5m、牆厚、欄杆高等設定。範圍與尺寸為模型選值，不是實測。
- `surface.js`：純幾何（不依賴 THREE），由道路路線與高度場推出牆線、牆頂與基腳；牆頂貼齊路面，基腳埋入地面下。renderer 與測試共用。
- `renderer.js`：混凝土牆身、欄杆柱與上／中兩道橫桿；牆身加入相機遮擋與碰撞。

不改道路路線、路寬、坡度、地形、建築或球場。網球場不再能從這段向陽路直接走下去。
