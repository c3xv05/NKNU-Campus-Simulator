# 生科 A／B 連接處（依平面圖，2026-11-23）

依使用者提供的生物科技館（A）／生物教學大樓（B）1F～3F平面圖重建兩棟之間的連接處，取代先前「B北端細翼等寬延伸＋5m小平台＋32階矩形東梯」的地圖推導。使用者決定：

1. 通廊最上層（2F）就是先前的 S05 T 字平台，高度對齊 S05，作為其他樓層的基準。
2. 連接處以平面圖為準。
3. 只有 1F、2F 相通（3F圖無連接）。
4. 東側往向陽路（S01）是坡道與階梯混合；平面照圖，高差等比例放大（見下）。
5. 花瓣廣場、方形廣場上方露天、花瓣圖案畫成鋪面。
6. 二樓 T 平台兩側斜線是 1F 小梯的投影；污水機房做成封閉量體、門關著、位置對齊圖面。之後要求把小梯做出來、平台下方架空（同日）。
7. 1F 通廊兩側都是落地窗。

## 來源與座標

- `scripts/biology_drawing.py`：PDF 向量讀出的圖面座標（A 1F 頁、B 1F 頁，約 9.40 pt／m）。通廊、花瓣廣場、坡道階梯區與污水機房共用中心線（A頁 x=467.4），放在既有 S05 T 支線接點 `facilities/biology-layout/layout.json` 的 joint 上；頁面向右＝由A往B，頁面向下＝往S05。
- `scripts/biology_layout.py`：推導 `campus.bioConnection`（`build-building-access.py` 與 `build-campus-corridors.py` 共用）。
- 執行端：`stair-layout.js`（坡道階梯區的平台／直梯／斜坡定義與高程換算）、`facilities/campus-corridors/`（1F通廊／2F平台樓板、T支線、廣場）、`facilities/biology-link/renderer.js`（落地窗、門、柱、欄杆、污水機房、花瓣圖案、階梯式花台、樹）。

## 內容

- **1F 通廊**：寬約 3.62m（圖面 503.32～537.4），A端玻璃面到B端門框約 19.3m；南側中段內凹到污水機房北牆。兩側落地窗（地板到二樓樓板底，豎框約1.2m），臨廣場兩組雙開門為開啟（可走），其餘門（兩端、往S05側兩道、污水機房門）關閉。8根方柱依圖面。
- **2F 平台**：圖面虛線範圍（比通廊寬，兩側各出挑約0.6m），露天；北緣全長、南緣（T支線以外）有欄杆。T支線12m、置中、垂直S05，沿用原設計，止於平台南緣。
- **花瓣廣場**：+510，含通廊前門廊帶約 12×13.9m；圓形與四組透鏡形（八瓣）圖案為鋪面貼花；兩側低花台。
- **坡道階梯區**（+0～+500，約 12×23.8m）：
  - 左右兩側各一道約1.8m直梯，每段升圖面1.6m（10階），左右錯開0.8m，中間為平台。
  - 中間7段之字形斜坡（寬約1.44m，每段在兩側平台間斜跨約7m、升圖面0.8m；第7段接+500小平台）。
  - 斜坡之間為階梯式花台，兩側牆邊也是花台；**花台就是花台，不種樹**（使用者 2026-11-25）。每一格花台與同一條線（同y）上的側梯踏階等高（左半跟左梯、右半跟右梯，格線落在該梯的踏階線上），不高出踏階；花台不能踏上去。
  - 最低一層 +0 平台在斜坡接觸範圍內保持水平，靠S01端順坡接實際路面；其外到斜交的S01路緣以貼地鋪面（`biology-s01-apron`）補齊。
- **污水機房**：圖面 6.6×5.0m，位在T平台下、兩道小梯的內牆之間；做成封閉實心量體（扣掉通廊凹處），門在北牆東側、關閉。
- **一樓門外的牆已拆**（2026-11-25）：梯井沿平台邊的支線側面不再做到一樓地面，免得在一樓平台上看到一面牆擋住通廊的門（只畫、不擋路，看起來像「穿牆」）。
- **+505 兩側小梯**（使用者 2026-11-23 要求建置、T平台下方架空）：通廊往S05側兩道門開啟；門外1F平台（約3.1m）接一段32級直梯（A 1F圖踏步、A 2F圖T支線兩側斜線投影＝同一段梯，頂點對齊圖面圓點），頂階接上T支線樓面。T支線在梯子上方開天井（`bioConnection.sideStairs[].well`），外側實心牆延伸到12m支線邊、高出支線樓面約1m；內側在支線樓面邊加欄杆；平台南緣跨過天井也有欄杆。梯寬約1.56m；級高依模型高差換算（約0.175～0.18m）。支線中段（污水機房以南、兩梯之間）是支線下方封閉空間（圖面兩側是牆）。

## 高程（使用者 2026-11-23 選擇第一種解法）

模型的 S01 在梯腳處比一樓低約11.5m，圖面只有5.15m（SRTM地形誤差）。平面完全照圖，高差以線性比例換算：圖面 +0 → S01 梯腳路面，圖面 +510 → 1F（`biologyTerraceScale`，目前係數約2.25，每段0.8m→約1.8m，斜坡約26%，梯級約0.36m）。日後地形修正後，比例會自動變回接近1。騎車不走階梯／坡道（沿用原規則）。
