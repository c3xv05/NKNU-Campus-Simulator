# 高斯大樓

修改 `building.json` 的 geometry 與 appearance 後，於專案根目錄執行 `python scripts/build-building-catalog.py`。

使用者提供之照片；依牆色、構架、入口及招牌重建，尺寸為近似值。

## 2026-11-18：依平面圖定位（物理系館）

- `source/floor-B.pdf`、`floor-1.pdf`～`floor-7.pdf`：學校營繕組公開的物理系館平面圖（S=1/200縮印）。
- `plan.json`：各層外框（致理圖面公尺框架，與 `buildings/zhili/plan.json` 相同）、2F露台「接未來廣場」、1F西側庭院。
- 定位：依致理1F圖面「物理系館」東北角階梯形外框；檢核：高斯1F西北視聽階梯教室的屋頂（2F露台）正好落在致理1F圖面南側的±0方格鋪面。使用者說明：致理1F＝寰宇1F＝高斯2F（下層廣場），致理2F＝寰宇2F＝高斯3F（上層廣場，高斯不接）。
- 外殼 `ring`＝3F外框截去東側露台（edge 0＝S05側主立面，北→南），比原位置北移約12m（北端約18.7m、南端約7m）。原輪廓保留為 `beforeDrawingFootprint`／`terrainRing`（地形墊與平台高程錨點不變，1F仍為遊戲35.45）。
- 2F露台併入中央廣場下層，下方1F視聽翼暫以實心磚基座表示；高斯其餘1F範圍與原外殼範圍不再是廣場。
- 待做：1F／2F可步行室內（task：用致理同一流程做1～3F）、1F西側庭院與上2F露台的寬樓梯、B1、依圖面立面。

## 2026-11-18：1F～3F 空房間室內（依使用者確認的平面判讀）

- `plan.json` 的 `floors`：物理館 1F～3F 判讀（房名照圖面手動標註；103／104 為同一間 L 形教室，2F 玄關上方兩間「未標示房間」），座標為致理圖面公尺；`floorOffsets` 為各層圖面對齊 1F 的平移，`stairCores` 為四座疊放梯間。
- `interior.json` 由 `python scripts/build-gauss-interior.py` 生成（沿用致理流程）：1F～3F 可走，4F～7F 實心但外牆窗依 3F 圖面；層高 3.6m，1F 仍為遊戲 35.45。
- 入口：1F 東側玄關（S05，門外戶外台階）、西側入口平台（門內平台＋台階）、西側庭院門；2F 兩道門通「接未來廣場」露台（下層廣場）。
- 1F 西側庭院與花園：中央廣場 `gaussCourt`／`gaussGarden`（高斯 1F 高）；寬樓梯由庭院上下層廣場。原本暫代的實心體與舊連通廊基礎在有室內後取消。
- 執行端與致理共用 `buildings/zhili/interior.js`（以 OSM 註冊多棟），最低層下方補基礎實心，避免地形裁切露縫。
