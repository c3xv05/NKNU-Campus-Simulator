## 1.1倍與場地保護

`modelScale=1.1`同時作用X/Y/Z，包括樓高、門窗、牆厚、設備、階梯、扶手及標示；不是只放大平面。由原比例0.04176套用1.1得到0.045936，沒有為避路再縮回去。外殼整體平移[-2,-1.5]m避開原道路與人行道，入口可由原P05步道到達；此為場景套合近似，沒有移動鋪面。

`geometry.ring`與原平台錨點保留作地形基準，原始高程、完整道路／通廊整平後網格、道路線位／坡度／寬度及人行道資料不改。放大後只在新建築內遮蔽原本可能穿過樓板的地面，沿用原三角面的高度／法線內插；外部地形形狀及行走高度不變，不抬高整片地形。基座只跟隨實際新外殼，不在外圍草地加舊輪廓的混凝土平面。植栽仍在固定程序生成後局部避讓模型，不更動其他區域的亂數序列。

牆厚、門寬、設備位置、樓梯階數及圖面套合仍是模型近似，非施工圖；浴室X符號不是電梯。

## 重建及驗證

```sh
python scripts/build-building-catalog.py
python tests/jiyuan-interior-geometry.py
node tests/jiyuan-interior.mjs
python -m http.server 8139
THREE_MODULE_PATH=/tmp/three.module.js python tests/jiyuan-interior-browser.py
```

建築目錄同步生成室內，不要重建整套道路或地形。核對圖另以`python scripts/build-jiyuan-review.py`產生（需PyMuPDF）。純測試包含房間／浴室不可侵入走廊、獨立／共用名單、浴室只接指定寢室、走廊側牆封閉、設備形狀不重疊、主通道三線、每層雙向樓梯、1.1倍渲染／碰撞一致、室內遮地面不改外部高度及重建一致。瀏覽器每層實走寢室／浴室門與三線走廊並檢查樓板／踏階射線，不能只驗證所有空間碰巧連通。

地形／道路比對基準為整合PR79／81後的`e10c351`（霽遠樓基型仍為PR77）；受限制環境可先`git show e10c351:data/campus.json > /tmp/jiyuan-fix-baseline.json`、`git show 8f9d50d:buildings/foresight/interior.json > /tmp/jiyuan-fix-old-interior.json`，再設定`CAMPUS_BASELINE_JSON`與`JIYUAN_BASELINE_INTERIOR`執行Node測試。
