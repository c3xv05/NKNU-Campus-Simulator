## 2026-11-10：主要幹道立面、實體連接區與開發者介面

使用者確認：生科 A/B、致理、高斯、歸燕食巢、霽遠樓所提供照片均是朝主要幹道的立面；其他牆面沒有同樣入口和標示。
本次以外牆法線及主要車道幾何選取單一正面，招牌只單面顯示；其餘面保留牆面和窗組，未確認用途的附屬建築不虛構入口招牌。

致理一、二樓與高斯為建築量體的連接，底下非懸空空橋。模型補上落地基座、下層連通與上層平台。
生科 A/B 平台下方改為實體基座，留出可下樓至東側馬路出口的樓梯井；樓梯踏階、人物高度與不可穿越的基座相配合。
這些長寬、踏階數、層高仍屬近似，之後以現場照片／使用者回饋校正。

入口不規則圓弧取消標線，補上貼花圃的瀝青接合帶。警衛室兩側採同一入口高程，橫向無高低差；前後路段平滑銜接。

封面開發者入口、左側圓形輔助鈕、開發者紀錄／問題回報／登出已加入。草稿自動保存、可下載備份，附目前位置與環境。
「送至 GitHub 儲存」會開啟填好的 Issue，須在 GitHub 完成送出；程式不將「開啟頁面」假稱為已同步。
GitHub 紀錄是公開的；不儲存 GitHub token，入口碼不代替 GitHub 帳號登入。

其餘建築調整依據：[外觀研究紀錄](research/buildings.md)。圖資大樓已依官方工程資料改為地上二層，並有地下一層；不能套用「所有教學大樓五層以上」。
未核對的寰宇、燕窩細部與附屬設施保持近似並標記待確認，沒有混用高科大或臺師大的照片。

故事種子只記錄於 [故事備忘](research/story-seeds.md)，尚未加入 NPC、任務或隨機事件。
