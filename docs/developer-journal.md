入口不規則圓弧取消標線，補上貼花圃的瀝青接合帶。警衛室兩側採同一入口高程，橫向無高低差；前後路段平滑銜接。

封面開發者入口、左側圓形輔助鈕、開發者紀錄／問題回報／登出已加入。草稿自動保存、可下載備份，附目前位置與環境。

GitHub 紀錄是公開的；不儲存 GitHub token，入口碼不代替 GitHub 帳號登入。

其餘建築調整依據：[外觀研究紀錄](research/buildings.md)。圖資大樓已依官方工程資料改為地上二層，並有地下一層；不能套用「所有教學大樓五層以上」。
