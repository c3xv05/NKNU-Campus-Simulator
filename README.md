# NKNU 燕巢校園模擬器

靜態 Three.js 校園探索，手機搖桿移動、右側拖曳視角；點小地圖或按 M 展開校園圖。左上提供大門、歸燕食巢、致理大樓傳送，並可切換騎機車。
大地圖可點建築或清單，顯示位置、探索狀態、直線距離及近似高差。

## 本機執行

```sh
python -m http.server 8000
```

開啟 http://localhost:8000/ 。Three.js 由 jsDelivr 載入；地形格網隨網站提供，遊戲中不需呼叫高程 API。
部署時需一併提供根目錄的 HTML、JavaScript 模組與 `data/` 內的 JSON 檔案。

## 驗證

```sh
node tests/terrain.mjs
node tests/zones.mjs
node tests/roads.mjs
node tests/travel-landscape.mjs
node tests/campus-realism.mjs
python tests/browser.py
python tests/zones-browser.py
python tests/road-browser.py
python tests/campus-features-browser.py
python tests/campus-realism-browser.py
```

瀏覽器測試需啟動上述伺服器，並安裝 Python Playwright 與 Chromium。
可用 `CHROMIUM_PATH` 指定瀏覽器；`THREE_MODULE_PATH` 可指定本地 Three.js 0.160.1
模組檔案，在測試時代替 CDN。測試的狀態讀取介面僅注入測試回應，不包含於正式頁面。

## 地形來源

見 [SOURCES.md](SOURCES.md)。資料為公開衛星高程近似重建，建築與運動場平台經簡化平整，
未宣稱為校園實測成果。以 `python scripts/sample-terrain.py` 可重取樣原始公開圖磚（需 Pillow）。

## 植被分區回饋

`zones.html` 提供不必啟動 3D 的分區圖，A 靠校門、D 靠科技大樓，共 12 區。
遊戲大地圖也能切換「植被分區」。分區顯示已收到的實地植被回饋，未提供的 B3、C1、D1、D2 保留待確認。
使用者可填寫分類與備註，草稿僅存於瀏覽器 localStorage；需複製文字貼回對話，
不會自動傳送或套用到模擬器。植被分區功能本身不會改動地形。

## 道路整平與標線

道路沿共享路網平滑縱坡，橫向維持平整，路口共用高程；路肩以近似挖填方接回地形。
地面三角形依道路範圍裁切，避免草地穿出路面；角色使用鋪面高程行走。
保留山坡走勢，並非把全校道路改成水平。原始衛星高程格網未改寫，實際道路坡度仍待實地校正。

鋪面及標線為自行繪製的台灣道路示意樣式。依 OSM 單行及步道資訊，分別使用
白色單行箭頭、雙黃線、白色邊線與不同步道鋪面；現場標線位置並未逐條測繪。

## 傳送與騎乘

- 點左上「快速傳送」選大門、歸燕食巢、致理大樓；電腦快捷鍵為 1／2／3。
- 點「騎機車」或按 R 上下車。W／S 加減速與倒車，A／D 轉向；手機搖桿前後加減速、左右轉向，右側拖曳獨立調整視角。
- 傳送會清除速度及輸入並同步鏡頭，保留探索進度與騎乘狀態。開地圖、切換分頁或視窗失焦會停止移動。
- 騎乘速度在道路與非道路區域不同，仍會碰撞建築、樹幹、入口花圃與警衛室。

## 已套用的植被回饋

A1、A3、B1、B2 為樹林；A2 主要為花田；C2 最北側道路以北為樹林、其餘空地為雜草；
D3 空地為雜草。C3 在使用者同一則訊息有樹林與雜草兩種描述，暫依最後一句配置為雜草，仍待確認。
建築、道路、水域、球場與操場會排除植栽。已移除 A1 擋土牆，校門內三角區加入尖端朝南的水滴花圃。
樹種、植株數量、牆高、花圃尺度與 C2 細部分界為可調整的示意實作，未宣稱實測。

道路使用連續三次內插銜接坡度及平滑法線；相鄰路口與平台以連續加權混合，減少階梯感。
地形顯示格網改為 4 公尺，不代表來源高程精度提高。樹冠遮擋鏡頭時會暫時隱藏，鏡頭也會避開建築。

## 實景校正與功能性場地

- 道路不再建立平頂路口平台，改以共用的連續坡面銜接交會路段與路肩；移除道路的逐段垂直裙牆。
- 白色邊線／行穿線與黃色分向線使用不受光照染色的材質；標線位置仍為示意配置。
- 校門兩側道路與北側接路依水滴花圃外緣重新對齊；小地圖使用同一份道路幾何。
- 校門至圖資大樓的師大路、清心路，以及歸燕食巢至致理南側的詠霽路，配置貼路人行道。
- 高斯 2F 與致理 1F 以同一標高的連通廊銜接，可從上層通行；走在地面不會突然跳上橋面。
- 人物約 1.76 公尺，教學樓以至少五層及樓層窗帶呈現；高斯七層、致理八層參考學校樓層使用資料，尺寸仍屬近似模型。
- 機車在道路最高可達 75 km/h；沿岸碰撞與既有碰撞仍生效。
- 四處湖泊具有凹入地形的湖盆、動態水面與通行阻擋，不是可走的藍色地板。湖深為示意值。
- 球場由北到南為風雨排球場、長條建築、風雨網球場、風雨籃球場；球場有棚頂、支柱與場線。
- 歸燕食巢北側建築標為詠絮樓；完整地圖新增場地與設施選取，並同步小地圖的人行道、湖泊、花圃與建築資訊。


## 照片外觀與獨立建築資料

每棟有立體模型的建築各有 `buildings/<id>/building.json` 與說明檔（共 19 棟）。
`geometry` 存輪廓、樓高與介紹，`appearance` 存牆色、窗框、正面方向、招牌與外觀類型。
有照片參考的生科 A/B、致理、高斯、歸燕食巢、霽遠樓採不同外觀；其餘保留簡化樣式。
新增外觀類型可擴充 `buildings/renderer.js`，不必改動遊戲控制。

修改各棟資料後執行：

```sh
python scripts/build-building-catalog.py
```

此工具同步 `data/campus.json` 空間索引及 `buildings/catalog.json` 外觀索引。
執行時只載入一份小型外觀索引，避免啟動時逐棟發出請求；牆面與窗框共用材質，
每棟細節依材質批次實例化，距離 145 公尺外只顯示簡化建築殼，並採節流距離檢查。
拆資料夾便於維護，真正減少繪圖負荷的是這些批次繪製及距離細節切換。

教學區中央平台連到高斯 3F、致理 2F、寰宇 2F，附坡道並納入人物通行。
生科 A/B 之間加入上層通道；照片不足以確定精確樓層、長寬與立面朝向，這些仍是近似重建。
大門取消原跨車道門樑，改為水滴花圃南端接中央警衛室、兩側各有閘門；閘桿為外觀，車道可通行。
道路與路肩使用連續高程，裁切地面保留原三角形內插，以寬緩路肩銜接路面，避免重採樣造成的接縫。
人行道裁掉車道重疊區，交會道路上的標線亦裁切，入口銳角線段已整理；機車上限現為 75 km/h。

新增驗證：`node tests/photo-buildings.mjs`、`python tests/photo-buildings-browser.py`。

## 開發者入口、紀錄與問題回報

封面點「開發者入口」，輸入 `0315`，左側會出現圓形「開發」按鈕。
可開啟開發者紀錄、問題回報或登出。填寫時自動保存本機草稿，附遊戲座標、視角與裝置資訊，並可下載 JSON 備份。
「送至 GitHub 儲存」會開啟填好的公開 Issue，需在 GitHub 完成送出；下次可於同一介面讀取。
程式不把開啟 GitHub 誤標為已同步，也不在公開前端放入 GitHub token。入口碼只控制介面，GitHub 寫入由 GitHub 本身的登入授權。

集中索引：[Issue #9](https://github.com/c3xv05/NKNU-Campus-Simulator/issues/9)。
後續討論先讀 [開發者紀錄](docs/developer-journal.md) 及含 `<!-- nknu-dev-record -->` 的 Issues。
未送出的本機草稿不會出現在其他裝置或遠端工具中。

## 建築連接與入口最新校正

- 生科 A/B、致理、高斯、歸燕食巢與霽遠樓只在面向主要幹道的一面設入口與招牌，其他牆面不複製入口。
- 致理／高斯連接下方補實體基座，下層為連通區，上層接中央平台；生科兩館平台下方也改實體。
- 生科平台留樓梯井，踏階通往東側向陽路旁出口，可實際上下樓；基座不可穿越。階梯屬建築樓梯，主要道路仍為連續斜坡。
- 校門兩側採共同高程，花圃邊緣補接合帶；不規則入口圓弧不畫標線。
- 圖資大樓依官方工程資料修正為地上2層、地下1層；其餘建築研究及待確認項目見 [外觀研究](docs/research/buildings.md)。

[故事備忘](docs/research/story-seeds.md) 保存六項新聞／Dcard 素材，僅供未來討論，沒有新增 NPC 或事件。

`python tests/developer-browser.py`、`python tests/connected-campus-browser.py`。

## 道路分區與地圖操作（2026-11-11）

小地圖及展開地圖均可雙指縮放，放大後單指拖曳，並可重設。一般地圖顯示校方路名；植被 R01–R12 與人行道 S01–S35 核對僅登入開發者後顯示。點分區／路段可定位並填寫，答案先存本機草稿，透過開發者問題回報完成 GitHub 送出後才可跨裝置討論。原 A1–D3 為歷史植被配置，新分區尚待重新確認，填寫不會立即改動場景。

入口路面是使用花圃精確輪廓作孔洞的整片瀝青。重建幾何依序執行 `scripts/build-entrance-apron.py`、`scripts/build-road-regions.py`、`scripts/build-sidewalk-sections.py`，產生檔案隨網站部署；產生環境需 Shapely，網站執行不需要 Python。

新增驗證：`node tests/map-review.mjs`、`python tests/map-mobile-browser.py`、`python tests/developer-browser.py`。
